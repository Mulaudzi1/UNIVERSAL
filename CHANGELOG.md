# Changelog

All notable changes to UNIVERSAL are documented here. The project follows Semantic Versioning once the language reaches a stable compatibility policy.

## [0.1.0] - 2026-08-27

### Added
- Rust compiler workspace with lexer, parser, AST, semantic analysis, IR boundary and interpreter.
- CLI commands for checking, running and build validation.
- Entity declarations, variables, optional properties, conditions, functions, validation and actions.
- Visual Studio solution with Cargo-backed compiler, CLI and test projects.
- Cross-platform CI, formatting, linting and test scripts.
- Language specification, architecture documentation and RFC process.
