# Roadmap

## 0.1 — executable language foundation
Lexer, parser, AST, nominal entities, variables, primitive expressions, optional properties, readable conditions, functions, validation events, action nodes, semantic checks, interpreter, CLI, tests, docs.

## 0.2 — semantic maturity and tooling
Modules, lists/maps, flow-sensitive optional narrowing, structured errors/results, formatter, REPL, richer diagnostics, initial typed IR lowering.

## 0.3 — capability runtime
JSON, HTTP client primitives, database provider interfaces, package manifest/lockfile prototype, effect/capability model.

## 0.4 — application platform
API framework, web application package, authentication/authorization primitives, secrets model, database migrations/providers.

## 0.5 — portable compilation
Stabilized Universal IR, WebAssembly backend, JavaScript backend, backend conformance suite.

## 0.6 — interoperability and native
FFI/provider ABI, native backend experiments (likely LLVM or Cranelift evaluation), performance work, debugger protocol.

## 0.7 — explicit AI capabilities
Typed probabilistic operations, provider abstraction, schemas, timeouts/cost policies, deterministic boundaries, provenance.

## 1.0 — stable ecosystem
Stable specification and compatibility policy, package ecosystem, LSP, formatter, debugger, production runtime, security review, conformance suite.
